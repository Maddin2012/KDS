Daten der alten Serviceliste sichern

Diese Datei liest die Listen, die die alte Serviceliste in diesem Browser gespeichert hat, und speichert sie als Datei KDS-Altdaten.json. An den alten Daten wird nichts verändert.

Nichts gefunden? So geht es auch

Die Datei muss im selben Browser (z. B. Chrome oder Edge) und mit demselben Windows-Benutzer geöffnet werden, mit dem früher die alte Serviceliste benutzt wurde.

Klappt es trotzdem nicht: die alte Datei (Serviceprotokoll (6).html) öffnen, F12 drücken → Reiter Konsole → diese Zeile einfügen → Enter. Dann wird KDS-Altdaten.json direkt heruntergeladen:
